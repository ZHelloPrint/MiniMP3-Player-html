# 🎵 Pocket Music Player

A cute, lightweight browser-based MP3 player inspired by classic Apple/iPod music players.
Drop your music in, and turn your browser into a tiny personal music library. ♡

## ✨ Features

* 🎧 Drag & drop MP3/audio files
* 🖼️ Automatic album-cover detection
* 🎵 Reads song metadata like title, artist, and album
* 💾 Saves your music library locally with IndexedDB
* ❤️ Favorite songs
* 🕘 Recently played songs
* 🔀 Shuffle & repeat
* ⏭️ Previous / next track controls
* 🔊 Volume control
* ⚡ Playback speed control
* 😴 Sleep timer
* 📚 Songs, Albums, Artists, Favorites & Recent views
* ↕️ Drag tracks to reorder your library
* 🎨 Multiple themes
* 🌈 Audio visualizer
* 🖥️ Fullscreen album-art mode
* 🎛️ Floating mini-player
* ⌨️ Keyboard shortcuts
* 🖱️ Interactive click wheel
* 📱 Responsive design

## 🚀 How to Use

1. Open the website.
2. Drag your MP3/audio files onto the player.
3. Or click **Add Music** to select files.
4. Your songs will appear in your library.
5. Click a song to start listening!

Your music stays in your browser using **IndexedDB**, so the files don't need to be uploaded to a server.

## 🌐 GitHub Pages

You can host this project for free using GitHub Pages.

After uploading `index.html` to your repository:

**Settings → Pages → Deploy from a branch → main → /root**

GitHub will provide a website URL for your player.

## ⚠️ Important

Music files are stored **locally in your browser**. They are not uploaded to the website or shared with other users.

Clearing your browser's site data can remove your saved music library.
